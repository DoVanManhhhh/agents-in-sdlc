**[GitHub Copilot CLI][about-copilot-cli]** は、GitHub Copilot をターミナルで使えるエージェント型コーディングアシスタントです。コードベースを探索し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインで行えるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして使い方を確認します。
2. 星評価の小さな変更を加え、ブラウザーでレビューして、最初の pull request (PR) を手動でマージします。
3. フィルター機能の Issue から開始し、Plan モードでアプローチを決め、Autopilot モードで構築して、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) server を追加し、ブラウザーでフィルター機能を確認します。
7. QA カスタムエージェントを作成して、要件、カバレッジ、検証の証拠をレビューします。
8. フィルター機能全体を確認し、Agent Merge を使って PR をマージします。
9. コンテキスト、モデル、共有、任意のクラウドへの委任に使う便利なスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR は2つ作成します。1つ目は星評価、2つ目は指示、スキル、QA プロファイル、テストを含むフィルター機能です。フィルター機能と品質に関するワークフローでは、1つの会話とブランチを共有し、各ツールでの作業を積み重ねます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランがない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の各機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合、管理者が Copilot CLI を有効にしていることを確認してください。
