Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y un backlog compartido. Planificarás cambios, crearás código, probarás el comportamiento, revisarás solicitudes de incorporación de cambios y gestionarás el trabajo con agentes mediante un proceso iterativo.

## Escenario

Eres un nuevo desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub. Incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad, como la accesibilidad y los estándares de código.

## Elegir un entorno

GitHub Copilot te acompaña en el entorno que elijas. Selecciona cómo quieres desarrollar. Cada taller tiene su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo, colabora en canvas y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abra.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
